# Admin translation glossary

Terms each translation uses everywhere, so the same English word always reads the same in a language. Keep them when you add or change strings. The full list per language, with notes, is in the sections below the table.

## Conventions

| Language | Conventions |
|---|---|
| Español (`es`) | Tú; infinitive buttons (Guardar); neutral Spanish for Spain and Latin America. |
| 简体中文 (`zh-Hans`) | No pronoun where possible, 你 when needed; full width punctuation; plurals use only other. |
| हिन्दी (`hi`) | आप; polite short buttons (सहेजें); common tech loanwords in Devanagari. |
| العربية (`ar`) | Modern Standard Arabic, right to left; verbal nouns for buttons (حفظ); six plural forms. |
| Português (Brasil) (`pt-BR`) | Você; infinitive buttons (Salvar). |
| বাংলা (`bn`) | আপনি; short buttons; Bengali danda for sentence ends. |
| Русский (`ru`) | Вы in lowercase; infinitive buttons (Сохранить); «ёлочки»; one, few, many, other plurals. |
| 日本語 (`ja`) | です/ます sentences; noun buttons (保存); 「」 quotes; plurals use only other. |
| Français (`fr`) | Vous; infinitive buttons (Enregistrer); non breaking spaces before : ; ? ! and inside « ». |
| Deutsch (`de`) | Du; infinitive buttons (Speichern); „…“ quotes; shortest natural wording for buttons. |
| Bahasa Indonesia (`id`) | Anda; short imperative buttons (Simpan); plurals use only other. |
| Türkçe (`tr`) | Siz forms; short buttons (Kaydet); suffix safe phrasing after placeholders. |
| 한국어 (`ko`) | 해요체 sentences; noun buttons (저장); particles like 을(를) after placeholders. |
| Italiano (`it`) | Tu; imperative buttons like WordPress it_IT (Salva). |
