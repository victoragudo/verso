# Code of conduct

Verso follows the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

## In short

- Be kind and patient. Many people here write in their second or third language.
- Welcome newcomers and questions of every level.
- Criticize code and ideas, never people.
- No harassment, insults, sexual language or imagery, or personal attacks, in any space of the project.
- Do not publish other people's private information.

## Where it applies

Issues, pull requests, discussions, code review and any other space that represents the project.

## Reporting

Report behaviour that breaks this code to the maintainer through a private message on GitHub ([@victoragudo](https://github.com/victoragudo)). Reports are handled in confidence.

## What happens next

The maintainer may edit or remove comments, close discussions, or ban a person from the project, temporarily or for good, depending on how serious and how repeated the behaviour is. The full guidelines are in the Contributor Covenant linked above.
