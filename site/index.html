Plugins

Extend it like any Laravel app.

A plugin is a folder with a verso.json, a service provider and your code. Routes, models, migrations and React screens work the way you already write them.

plugins/bookings/verso.json

{
  "name": "Bookings",
  "slug": "bookings",
  "version": "1.0.0",
  "admin": { "group": "tools" },
  "capabilities": ["bookings.manage"]
}

FAQ

Questions people ask first.

Is Verso free?

Yes. Verso is open source under the MIT license, with no paid edition. Every feature, including the bundled plugins, is free.

How is Verso different from WordPress?

Verso is built on Laravel and includes what most WordPress sites add with plugins: a page and theme builder, SEO analysis, forms with spam checks, a roles editor, popups and redirects. Plugins and themes are scanned before they are installed.

What does Verso need to run?

PHP 8.4 or newer and SQLite, MySQL or PostgreSQL. Install it with composer create-project victoragudo/verso, or upload the release zip, which includes all dependencies. To try it without PHP, run it with Docker: one compose file starts Verso and MariaDB. A web wizard then sets up the database and the admin account.

Can I build my own themes and plugins?

Yes. Themes are Blade views with a theme.json file, and plugins are folders with a verso.json manifest and a Laravel service provider. Verso checks both before install.

Up and running in five minutes.

One command, then open the browser. The wizard asks for the database, your admin account and what your site is for.

$ composer create-project victoragudo/verso my-site
$ cd my-site
$ php artisan serve

Needs PHP 8.4+, Composer and Node.js 22+ once, to build the admin.

$ curl -fsSL https://raw.githubusercontent.com/victoragudo/verso/main/docker/compose.yaml -o compose.yaml
$ docker compose up -d
# open http://localhost:8000

No PHP or Node.js, only Docker. SQLite works as is; for MariaDB the wizard uses the host mariadb. Docker guide

Release zip · any hosting

Everything included: no Composer or Node.js needed. Upload it, point the web root at public/ and open your site.
